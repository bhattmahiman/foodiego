# Foodiego 🍔

A modern food delivery app UI built with **Flutter** and **Dart**, featuring restaurant discovery, food categories, cart management, checkout, delivery address management, and order confirmation.

## ✨ Features

- 🏠 **Restaurant discovery** — browse popular restaurants.
- 🍔 **Food categories** — explore food through category sections.
- 🛒 **Cart management** — add items and review your cart.
- 📍 **Delivery addresses** — add and select delivery addresses.
- 💳 **Checkout UI** — choose a payment method and review the order summary.
- ✅ **Order confirmation** — view a confirmation screen after placing an order.
- 🎨 **Modern UI** — clean layout with a vibrant orange theme.

## 🛠️ Built With

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)
- Material Design widgets

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart) (included with Flutter)
- Android Studio, VS Code, or another supported editor
- An Android emulator or a connected device

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/foodiego.git
   ```

2. Open the project folder:

   ```bash
   cd foodiego
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Check your Flutter setup:

   ```bash
   flutter doctor
   ```

5. Run the app:

   ```bash
   flutter run
   ```

> Replace `YOUR_USERNAME` in the clone URL with your GitHub username.
